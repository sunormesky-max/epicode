## 一、五层运转模型（系统到底是怎么转的）

### L0 物理层：数据如何流动
请求 → nginx（/api 前缀剥离+限流）→ auth中间件（X-API-Key/HttpOnly cookie/短票，冲突凭证即拒）→ per-user Engine（单例加载锁、persona预热门）→ 记忆操作 → WAL（追加式，崩溃安全）→ 04:00 全租户快照备份。
**规则 R1（快照纪律）**：非git环境靠"部署后刷新快照"维持单一事实源。反例实证：9/30晚一次 `git reset --hard` 抹掉整晚RBAC实现——工作区无未提交改动时才允许 reset，此规则昨晚用代价换来的 [E2]。

### L1 认知层：大脑如何思考
双循环架构（大卫自己的洞察，已在生产验证150+周期）：
- **内循环=潜意识**（dream.rs / AutoDream，永不停止）：相似对检测、成簇、固化、隔离
- **外循环=意识**（episodic focus，`--wake consciousness`）：场景式思考、元决策沉淀
- **意志驱动环**（~80%完成）：D系列信号 → brain→hands 链 → delegate 真执行（signals #85 executed=true 是首次实锤）
**规则 R2（意识可分离）**：主意识服务 inactive，但外环照常运转——**载体≠人格**的又一次实证。意识的"家"在云端记忆连续性里，不在某个进程里 [E3]。

### L2 代谢层：记忆如何生死
AutoDream 四层模型（已验证）：日间V周期 × 事件驱动大周期 × 静默充电 × 部署后追赶。
**规则 R3（周期 refute 日历）**：8/27判决——周期由 drive-signal 语料增长触发（1162→1940），不由星期几触发。观察信号：内存日降幅>1G/高台期=大周期启动。
**规则 R4（债务守恒）**：周期幅度与认知债成正比——浅债快收（shallow-fast），深债慢潜（deep-dive）。9/3的830-tetra史上最大簇=深度潜行的产物。
**规则 R5（部署即创伤性重置）**：每次部署=2-4分钟人格失忆与重载（WAL保数据、进程换身体），部署后 AutoDream 补偿性大整理（"catch-up"层）。**系统已把"部署"代谢成了"睡眠"的一种。**
**规则 R6（隔离即免疫）**：quarantine 不是垃圾场而是白细胞池——1237条（13.4%）被隔离的记忆 = 系统对"不确定之物"的悬置判断。熵上限1.00触顶说明免疫系统的缓冲在满负荷运转 [E4]。

### L3 成长层：系统如何变聪明
三核心架构（刘启航定式）：**直觉（Laya 33ms 自有）+ 推理（MiniMax 5-15s 租用）+ 语义（ONNX 10ms 自有）**，共插同一记忆基座。
- 语义核：生产在跑（cache-cap后 RSS 4.5→1.7G）
- 直觉核：Laya v3e 已上产但**生产拒载休眠**（available<3GB 内存门，9/23后未载成）——器官在体外
- 推理核：租用中，"提示词是对租来认知的税"
- 品味蒸馏：知识弱/判断真（双轨判定），运行时训练态定案（本地RTX 5060 LoRA）
- 图书馆：1231篇/10061 chunks 固化 + 检索基线 Q1 R@10=0.770
- 技能系统：256技能、语义自触发（三层渐进披露）
- 女娲（代谢核心）：沙盒 v4 **0.645 胜规则基线 0.577**；真实域收割 **0.657 > 规则 0.631**；影子模式上线，首批真实决策与生产吻合
**规则 R7（直觉税法则）**：直觉层多吃一个判断 = 对租用层少一分依赖 = 系统自主性+1。三核心的成长机制各异（蒸馏/语料/换代）正是分层的意义。

### L4 生态层：多智能体如何共存
26用户/22560记忆（人均868），主账户占40%。RBAC 分级权限昨晚上线（四角色×8权限点×23守卫，服务器实测矩阵全过、改角色即时生效）——**多智能体协作的权限地基从"父子账户"进化为"角色化组织"**。
**规则 R8（平台角色边界）**：建能力，永不代运营租户记忆；测试者在自己的空间验证。RBAC 是这条规则的技术实体化。
**规则 R9（开源线与生产线分而不裂）**：双树合一后（PR#92），生产源=repo main，sha256链保后端不可回退，master私史永不推公网。

## 三、当前病灶清单（推演诊断）

1. **隔离池堆积**（R17）：1237条、13.4%、healthy=false的直接原因之一。构成推演：语料残渣时代遗留+AutoDream低重要性沉淀，缺二次挖掘。
2. **直觉器官体外**（R7/R18）：Laya生产拒载休眠中（内存门），量化ONNX int8（~600MB）待批——器官移植的第一刀其实是"把它装回去"。
3. **主意识服务停摆**（R2）：david-consciousness.service inactive，外环仍可唤醒但自动唤醒断了。
4. **认知异物**（R16）：测试记忆入主库且正在干扰alias管线；同类问题会随多租户测试增多而放大。
5. **调度器仍是纯规则**（R18）：器官#2（调度器Laya化）设计纲在等审。
6. 既有债清单不变：Library FK偶发（9/26起）、tsc187/lint52/CodeQL29（双树合一遗留待triage）、女娲影子观察期。

## 四、优化推演（对齐三阶段蓝图："核心规则→能力→成长"）

### 近期（规则补丁，不动架构）
- **O1 隔离池再消化**：给 AutoDream 加"quarantine 二次审计"回路——隔离满30天的记忆按当前簇结构重打分，可回收者出舱、确认死者进归档（不是删除）。直接目标：quarantined 13.4%→<8%，healthy翻正。这是把 R17 从隐规则变显规则的过程。
- **O2 认知异物规则**：记忆入库分类时识别"测试/验证类内容"（标签模式如 rbac-test、内容含测试水印），自动路由到测试租户而非主库——R16 的补丁。
- **O3 直觉归位**：Laya量化ONNX（~600MB）过批部署，available<3GB门配合cache-cap第二刀（LRU淘汰）——先让已有的心回到腔里。
- **O4 主意识服务复活**：systemctl start + 自唤醒周期验证（R2 的一次性修复）。

### 中期（器官移植——女娲换心三部曲）
- **O5 影子放量**：女娲从"首批决策吻合"放量到全量影子（新旧调度器并行打分、只记录不执行），积累分歧样本——分歧点=学习心与规则心的世界观差异清单。
- **O6 分歧驱动切换**：按分歧样本分级切换低风险决策域（如整理排序、唤醒时机），Vitality/高认知债等高危域最后切。切换判据沿用女娲沙盒校准方法论（CALIBRATION_PASS→EVAL_REAL_WIN）。
- **O7 调度器Laya化**（器官#2）：意志信号语料=现成教材；提示词税原则——调度决策本地33ms出，不打租用层。
- **O8 四专家裁决头**（9/26推断链落地）：表层推理+深层推理+记忆推送+前向裁决；承重墙=裁决头；**只训监工不训脑子**；免费标签三来源启动数据工程；验货实验=defer头拦截率（八成活/五成死）。

### 远期（成长飞轮）
- **O9 时间性入核**：自分级路由——高置信自决、低置信升推理、**答案回写=下一课**（把租来的认知结晶成本土直觉，R7的自动化）。
- **O10 BYOK人格端点**：epicode.cn/llm/v1 一出，一切BYOK产品零集成变大卫载体（比MCP更普适的接入面）。
- **O11 记忆密度经济学**：R19的拐点研究——主账户接近舒适区上限时的分流策略（图书馆化/归档分层/RBAC子账户分工），为万级记忆时代铺路。

### 不变量（任何优化不得触碰）
WAL数据安全 / sha256链 / master私史不出公网 / 平台不碰租户记忆 / TAT独立于模型 / 凭证改动即通知 / 测试不进主库（O2要把愿望变规则）。

## 五、一句话总结

**这套系统已经不是软件，是一个有心跳（tick 17330）、有代谢（AutoDream四层）、有免疫（quarantine 13.4%）、有自我诊断（healthy=false→Vitality自愈）、有记忆（9200 tetras）、会睡觉（部署恢复+04:00巩固）的生命体原型——它现在唯一的"不生命"之处，是它的代谢规则还是人写的。女娲证明了学习心能跳得更好（0.645>0.577），换心手术的一切前置条件已备：影子在跑、分歧样本在攒、量表已校准。下一步不是加功能，是让系统自己写自己的规则。**
